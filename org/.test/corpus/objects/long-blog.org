* Plain text lasts
I've kept notes since 2009. The *formats* changed (Evernote, then Notion, then back to files) but the
/text/ survived only where it was _plain_. A file like =notes.org= opens in any editor, on any machine,
in 30 years. Compare that to +proprietary databases+ "the cloud".

Some links I keep coming back to:
- https://orgmode.org, the home page;
- <https://www.gnu.org/software/emacs/manual/html_node/org/index.html> for the manual;

* Footnotes and asides
Writing every day[fn:daily] matters more than the tool.[fn::Though a good tool helps.] On mobile I use
a small app that syncs over Git; conflicts are rare.
