## Page tabs
Pages joined as tabs of one: each shows a strip under its title. The first file lists the others, `tabs: [People map]`
(file names, like a `[[link]]`; one beside it first), and each may name its label, `tab: Map` (else its file name). A
tab whose `plugin:` is off is left out. `/api/render` says which tab a page is, with links to the others.
