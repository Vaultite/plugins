## Dock icon
The desktop app's Dock icon can be another picture, to see how an icon looks there: "Use as Dock icon" in an image's
menu (a vault file, or one open from outside the vault), "Set Dock icon from a file…" (the palette: any image on the
Mac) and "Reset Dock icon". The image is drawn on Apple's icon grid (824 of 1024 px, centred), so a full icon with its
rounded tile sits like the Dock's other icons. It's kept on this Mac (the app's userData, not the vault) and set again
at each launch; only the Dock shows it, while the app runs. Nothing is written to the vault.
