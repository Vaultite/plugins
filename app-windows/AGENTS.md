## App windows
Other Mac apps in a desktop app tab: `view:app/<bundle id>` (`vau open "view:app/com.spotify.client"`; one window a tab, `:<window>` once it has one) or "Open app in
a tab…". The app's window sits behind the tab (needs Accessibility permission, and the window on the current Space);
closing the tab gives it back (a window the app made for the tab, none being free, is closed instead); the tab's menu
has Close <app> window, as its close button does. Floating windows (picture in picture) never get a tab. A window on
another desktop stays there (macOS can't move another app's window between desktops): its tab says so, with Go to it
and Use a window here. An app coming in front with a tab's window (a link opened in it, ⌘Tab) shows its tab. Tabs and the picker show the apps' own icons. While one is open, ⌃⌘P opens the palette from any
app. Nothing is kept in the vault.
